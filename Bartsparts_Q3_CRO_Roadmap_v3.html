Q3 · Test 1 · #04 Approved

Simplify the homepage search bar

Test name
Simplify the homepage search bar (#04)
Problem
The search area carries extra weight — a “Shop by Brand” dropdown and a rotating hero slider — that distracts from the primary task. Heatmap: 43% of homepage clicks go to search, <1% to brands, <2% to nav.
Solution
Simplify the search bar: remove the “Shop by Brand” button and drop the hero slider (single static banner). Keep the same copy, CTA and placeholder so only the structure changes.
Hypothesis
If we simplify the search bar and remove the slider, homepage search-submit rate increases because the primary action is clearer and less distracting. Guardrail: CVR / RPV.

Q3 · Test 3 Approved

Repurpose the header: brands → simplified navigation

Test name
Repurpose the header: brands → simplified navigation
Problem
The header’s prime space holds 6 brand logos that barely get used — heatmap shows <1% of clicks on brands and <2% on nav, vs 43% on search. The top black nav bar adds clutter without pulling traffic.
Solution
Move the brand logos into an “Our Brands” carousel below the hero, place the navigation links where the brands were, and drop the black nav bar. Keeps the brand path available lower down while making search the clear focus.
Hypothesis
If we simplify the header (brands out, nav in, black bar removed), search focus and usability improve while brand-led buyers still reach brands below the hero. Primary metric: search-initiation; guardrail: brand-page and nav click-through must hold. CVR / RPV.

In-stock quick filter

Test name
In-stock quick filter
Problem
Stock is a primary purchase driver, but the current filters emphasise brand, category, price, featured products, and free shipping. Competitors (All States, AUTODOC) make availability easier to act on.
Solution
Add one “In stock now” filter chip above the search results.
Hypothesis
If we add an immediate in-stock filter, search-results-to-product-detail rate increases because buyers can remove unavailable options with one action. Guardrail: CVR / RPV.

Q3 · PDP · Test 2 Approved

Warehouse-scoped stock labels

Test name
Warehouse-scoped stock labels
Problem
On multi-warehouse products, “Stock” is the selected warehouse while “Total Stock” is availability across all warehouses (e.g. 1 in the selected warehouse, 15 in total). A generic “[n] units in stock” would be ambiguous and could misrepresent the selected offer.
Solution
Change only the stock labels to “This warehouse: [qty] in stock” and, when others have stock, “All warehouses: [total] in stock.” Single-warehouse products show only the first label.
Hypothesis
If we distinguish selected-warehouse stock from total marketplace stock, add-to-cart rate increases because buyers understand both the quantity on the current offer and the alternatives. Guardrail: CVR / RPV.

Q3 · Cart · Test 5 · checkout priority Approved

Set shipping-cost expectations before checkout

Test name
Set shipping-cost expectations before checkout
Problem
The cart shows a subtotal but no signal that tax and shipping are still to come, so buyers reach the payment page, see a higher number, and drop off — a likely driver of the checkout drop-off Tina is seeing.
Solution
Make the pending cost explicit: change the shipping row to a clear “Calculate shipping” action and label the Grand total “excl. tax & shipping.” Once calculated, Grand total = subtotal + shipping. (Final copy to be checked against competitors.)
Hypothesis
If we set correct cost expectations in the cart, checkout drop-off decreases because buyers aren’t surprised by tax/shipping on the payment page. Guardrail: CVR / RPV.
