Make the mood
easier to choose.

Five CRO concepts to make the existing Intimacy filter easier to discover and use—without introducing new matching categories.

THE RECOMMENDATION / 01
Put a simple, optional Mood choice above “Find a Match.”
Show Casual and Intimate as visible choices. Make their use clear before the user starts searching.
01 / Primary experiment

Bring Mood to the decision point.

Place an optional, directly selectable preference inside the matching card, just above the primary CTA.

Recommended first test

Problem

Users may start matching before noticing a preference that is below the main action.

Solution

Give Mood its own visual block, show both existing options, and retain an explicit Off state. A user can start without making a selection.

Hypothesis

If the optional preference is visible before matching, then more eligible users will make an explicit selection, because they can discover and choose it at the moment of intent.

02 / Alternative experiment

Make preferences easier to scan.

Keep the preference within Match Preferences, but replace the switch and dropdown with an exposed choice.

Lower-disruption option

Problem

Even when the preferences panel is seen, the switch plus disabled dropdown can make the options easy to overlook.

Solution

Show Mood first within the panel, with the same explicit Off, Casual and Intimate choices.

Hypothesis

If the existing choices are visible without opening a dropdown, then more eligible users will select one, because the options are easier to understand and act on.

03 / Alternative experiment

Add a gentle reminder near the CTA.

Keep the current filter in Match Preferences and offer a compact shortcut before users start matching.

Lightweight discovery

Problem

Some users may act on Find a Match before reaching the existing preference.

Solution

Show a small Mood shortcut above the CTA. Opening it reveals the existing choices without moving the preference itself.

Hypothesis

If users see a concise Mood shortcut near the CTA, then more will explore and select a preference, because the feature is discoverable at the point of intent.

04 / Alternative experiment

Explain the choice in context.

Make Mood options visible in Match Preferences and give each a short, product-approved explanation.

Clarity-led

Problem

The current control gives no visible guidance on what either option means.

Solution

Present two selectable cards with brief definitions, plus a clear Off state. Each option can include a concise explanation.

Hypothesis

If people understand what each option represents, then more users will confidently select a preference, because they can assess the choice without guessing.

05 / Alternative experiment

Show the active choice at a glance.

Keep the control in Match Preferences, and add a live preference summary next to the match action.

Status & control

Problem

When a preference is farther down the page, users may not know its current state when starting a match.

Solution

Add a status row near the CTA with an Edit link to the existing filter. In the demo, Edit reveals the selection panel below.

Hypothesis

If users see their filter state when deciding to match, then more will review and deliberately select a preference, because the setting is both visible and easy to revisit.

06 / Measurement plan

More use. Healthy matching.

Randomize eligible users consistently, split by text/video and device, and measure from exposure—not only from those who interact.

PRIMARY
Explicit Mood selection rate

Eligible exposed users who select Casual or Intimate at least once ÷ eligible exposed users. Count only deliberate selections, never the displayed default.

BEHAVIOR
Selection at match start

Match starts with an active selected filter ÷ all match starts. Compare Casual vs Intimate and review by chat mode and device.

GUARDRAILS
Connection & experience

Match-start rate, successful connections per exposed user, time to connection, skips/reports and meaningful-chat proxy, subject to data availability.
