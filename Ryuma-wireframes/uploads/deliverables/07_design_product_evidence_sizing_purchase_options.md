# Ryūma Stage 1: Design, Product Evidence, Sizing and Purchase Options

**Goal:** Create a premium visual system while giving customers enough proof to choose a product and size confidently.

## Design system

| Element | Recommendation |
|---|---|
| Color | Neutral base, strong black/white contrast and one controlled accent inspired by the brand identity. |
| Typography | Display type for editorial headings; clean sans-serif for body copy, prices, navigation and controls. |
| Photography | Mix styled campaign imagery with clear garment, fit and construction details. |
| Layout | Generous spacing, consistent grid and strong content hierarchy. |
| Buttons | One primary solid style, one secondary outline style and text links for low-priority actions. |
| Icons | Minimal, consistent line icons used only when they improve scanning. |
| Motion | Subtle transitions; no autoplay or decorative movement that delays shopping. |

The store should feel editorial but remain easy to use. Commerce information must never be hidden for visual effect.

## Product evidence

Every product page should contain:

| Evidence area | Required content |
|---|---|
| Material | Fiber composition and verified fabric weight |
| Construction | Stitching, ribbing, seams and garment finish |
| Decoration | Print, embroidery or application method |
| Fit | Regular, relaxed or oversized; product-specific guidance |
| Scale | Model height, worn size and front/back on-body images |
| Origin | Production and decoration location, when approved |
| Care | Washing, drying and ironing instructions |
| Design | Short meaning, inspiration and artwork detail |
| Service | Delivery coverage, returns window and support link |

Use close-up photography beside technical claims. Avoid unsupported terms such as “luxury,” “sustainable” or “best quality.”

## Product image set

Minimum per product:

1. Front on-model
2. Back on-model
3. Front garment view
4. Artwork close-up
5. Fabric/construction close-up
6. Fit or side-angle image

Add video only when it shows movement, drape or fit better than photography.

## Sizing system

### Visible beside size selection

- Size buttons
- Fit label
- Model height and worn size
- Size Guide link
- Short between-size advice

### Size Guide

| Section | Content |
|---|---|
| Garment measurements | Chest width, length, shoulder and sleeve in cm |
| How to measure | Simple garment diagram and instructions |
| Fit guidance | Intended silhouette and how it should sit |
| Model reference | Height, build and worn size |
| Comparison | Optional comparison with a familiar garment |

Use garment measurements rather than body measurements unless both are clearly labeled. Keep the guide in a drawer or modal so selected variants are preserved.

Do not preselect a size. If Add to Cart is clicked without a size, highlight the selector and show a direct instruction.

## Purchase options

| Priority | Option | Rule |
|---:|---|---|
| 1 | Add to Cart | Main full-width CTA |
| 2 | Accelerated checkout | Shop Pay, Apple Pay or Google Pay when available; visually secondary |
| 3 | TWINT | Enable for eligible Swiss customers paying in CHF |
| 4 | Guest checkout | Always available |
| 5 | Quantity | Default to one; keep control simple |

Show the active-market price, selected variant, stock state and key delivery/returns message before purchase.

[Shopify Payments in Switzerland](https://help.shopify.com/en/manual/payments/shopify-payments/supported-countries/switzerland/payment-methods) supports cards, Shop Pay, Apple Pay, Google Pay and local methods. [TWINT](https://help.shopify.com/en/manual/payments/shopify-payments/local-payment-methods/twint) requires an eligible business, Swiss customer location and CHF checkout.

## Required decisions and assets

- Confirm fabric composition and weight
- Confirm production and decoration methods
- Confirm fit for each silhouette
- Create final garment measurements
- Select models and record their height/worn size
- Approve cultural references and design stories
- Confirm shipping, duties and returns terms
- Confirm Shopify Payments and TWINT eligibility

## CRO rules

- Place essential fit and delivery information near Add to Cart.
- Use specific evidence instead of repeated premium claims.
- Show unavailable variants before the customer clicks.
- Keep Add to Cart visually dominant over express options.
- Never use false scarcity or preselected add-ons.
- Validate the size guide with real samples before launch.
