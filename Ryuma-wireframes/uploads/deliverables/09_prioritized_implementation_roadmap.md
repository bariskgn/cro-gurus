# Ryūma Stage 1: Prioritized Implementation Roadmap

**Goal:** Launch a credible, conversion-ready Shopify store without adding unnecessary complexity.

## Priority summary

| Priority | Focus | Outcome |
|---|---|---|
| P0 | Decisions, product data, core design/build and launch QA | Store is ready to sell |
| P1 | Trust, retention and optimization using real data | Improve conversion and repeat purchase |
| P2 | Range, market and personalization scale | Support growth without rebuilding |

## P0 — Launch critical

### 1. Confirm commercial decisions

- Launch audience: men, unisex or both
- Launch markets and languages
- Product range, prices and inventory
- Shipping, duties, tax and returns policy
- Payment methods and TWINT eligibility
- Final brand assets, typography and tone

**Dependency:** Complete before final UI and copy.

### 2. Build Shopify foundation

- Configure Shopify Markets, CHF/EUR and domain structure
- Set product taxonomy, options, metafields and metaobjects
- Create product, collection and design-story data templates
- Build automated category collections and manual Launch Collection
- Configure navigation, footer, search and redirects

**Outcome:** Clean structure that can scale.

### 3. Create the design system

- Select and configure Prestige; use Stiletto as the approved alternative
- Define colors, typography, buttons, spacing and image ratios
- Build reusable content sections
- Confirm desktop and mobile behavior

**Outcome:** Consistent premium storefront.

### 4. Build core customer journey

Build in this order:

1. Header, navigation and footer
2. Product page
3. Collection page
4. Cart drawer
5. Homepage
6. Search and help/policy pages

The PDP comes first because product data, sizing and purchase behavior affect every other page.

### 5. Produce content and assets

- Product and campaign photography
- Product specifications and size guides
- Design stories and brand copy
- Shipping, returns, FAQ and care content
- English and approved German translations
- SEO titles, descriptions and alt text

**Dependency:** All product claims must be verified.

### 6. Configure integrations

- Shopify Payments and TWINT
- Search & Discovery
- Translate & Adapt when multilingual
- Email capture and core lifecycle flows
- Review collection
- GA4, Shopify analytics and consent settings

### 7. QA and launch

- Test mobile and desktop layouts
- Test every product, variant and stock state
- Test CHF/EUR, markets, languages and payments
- Test shipping, tax, duties and discount behavior
- Test cart, guest checkout, emails and order confirmation
- Check accessibility, redirects and broken links
- Check page speed on real mobile devices
- Validate analytics events

**Launch gate:** No placeholder copy, empty reviews, hidden fees, broken variants or unsupported claims.

## P1 — First optimization cycle

Start after enough live behavior and customer feedback exists.

- Collect verified reviews and fit feedback
- Improve size guidance using returns/support data
- Refine search synonyms and product sorting
- Add customer imagery with permission
- Optimize welcome, abandoned-cart and post-purchase email
- Review homepage-to-PDP, Add to Cart and checkout drop-off
- Measure native complementary-product clicks, conversion and AOV
- Run usability tests before traffic supports A/B testing
- Test hero message, quality proof and PDP reassurance

## P2 — Scale

- Add Women navigation and collections when products are live
- Add market-specific merchandising and content
- After 20+ products, evaluate Rebuy for advanced personalization or Selleasy for simpler upsells
- Introduce advanced returns, loyalty or referrals only when justified
- Add bundles and back-in-stock flows where commercially useful
- Expand design-story pages and editorial content
- Consider personalization for new/returning visitors

## Recommended ownership

| Area | Owner |
|---|---|
| Brand, claims and creative approval | Ryūma |
| UX, CRO and content hierarchy | CRO/design team |
| Theme setup and custom development | Shopify developer |
| Product data and merchandising | Ryūma/e-commerce manager |
| Translation and legal review | Qualified local reviewers |
| Analytics and QA | CRO/development team |

## Launch success criteria

- Customers understand the product and brand within five seconds.
- Every product has complete evidence and sizing information.
- Products are reachable within two taps from the homepage.
- Add to Cart, cart drawer and checkout work across active markets.
- Prices, duties, delivery and returns are clear.
- Mobile experience is fast and usable.
- Analytics tracks the full shopping journey.
- The team can update products and stories without developer support.
